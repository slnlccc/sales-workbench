# 销售工作台小程序

基于微信云开发的销售全流程管理小程序，支持云端数据共享。

## 目录结构

```
miniprogram/
├── app.js                 # 小程序入口，初始化云开发
├── app.json               # 全局配置
├── app.wxss               # 全局样式
├── project.config.json    # 微信开发者工具项目配置
├── cloudfunctions/        # 云函数
│   ├── login/             # 登录（获取 OpenID）
│   ├── projects/          # 生产项目管理 CRUD
│   └── contracts/         # 合同管理 CRUD
├── pages/
│   ├── index/             # 工作台首页
│   ├── projectManager/    # 项目管家（生产项目+合同绑定）
│   └── contractManager/   # 合同管理（回款跟踪+关联项目）
└── components/
    └── riskBadge/         # 风险标签组件
```

## 快速开始

### 1. 注册微信小程序并开通云开发

1. 前往 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序账号
2. 登录后进入「开发」→「开发管理」→「开发设置」，获取 AppID
3. 点击「云开发」按钮，按指引开通云开发环境，记录「环境 ID」

### 2. 导入项目到微信开发者工具

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具，点击「导入项目」
3. 选择 `miniprogram` 文件夹所在路径（即包含 `project.config.json` 的目录）
4. 填入你的 AppID，勾选「不使用云服务」之外的云开发选项（或先导入再开通）
5. 点击「确定」导入

### 3. 配置云开发环境 ID

打开 `app.js`，将 `env: ''` 替换为你的云开发环境 ID：

```js
wx.cloud.init({
  env: 'your-env-id-here',  // <-- 替换为你的环境 ID
  traceUser: true,
})
```

### 4. 创建数据库集合

在开发者工具中：
1. 点击顶部「云开发」按钮打开云开发控制台
2. 切换到「数据库」标签
3. 点击「添加集合」，依次创建：
   - `projects`（生产项目）
   - `contracts`（合同）
4. 为两个集合设置权限：选择「所有用户可读，仅创建者可读写」或「所有用户可读可写」（根据团队需求）

### 5. 部署云函数

在开发者工具中：
1. 右键 `cloudfunctions/login` 文件夹 →「创建并部署：云端安装依赖」
2. 右键 `cloudfunctions/projects` 文件夹 →「创建并部署：云端安装依赖」
3. 右键 `cloudfunctions/contracts` 文件夹 →「创建并部署：云端安装依赖」

### 6. 运行

点击开发者工具顶部的「编译」按钮，即可在模拟器中预览小程序。

点击「真机调试」→「扫码真机调试」，可用手机扫码体验。

## 功能说明

### 项目管家
- 生产项目台账表格（横向滚动，支持 20 列信息）
- 搜索：客户 / 产品 / 图号 / 生产编号
- 筛选：合同状态、发货状态、日期范围
- 统计：项目总数、总金额、有合同数、已发货数
- 操作：查看 / 编辑 / 删除 / 新增
- **合同绑定**：编辑项目时可下拉选择已有合同，或输入新合同号自动创建并绑定
- 逾期预警：未发货且超期项目标红提示

### 合同管理
- 合同台账表格
- 搜索：客户 / 合同号
- 筛选：回款状态
- 统计：合同总数、总额、已回款、部分回款、待回款
- 操作：查看 / 编辑 / 删除 / 新增
- **关联项目**：查看合同时自动列出所有绑定的生产项目明细

## 云端数据共享

所有数据存储在微信云开发数据库中：
- 同一云开发环境下的所有用户共享数据
- 无需自建服务器和域名
- 微信原生登录，自动识别用户身份
- 可通过「数据库权限」控制读写范围

## 后续扩展

当前已实现核心模块（项目管家 + 合同管理），其他模块可按同样模式扩展：
1. 在 `pages/` 下新建页面
2. 在 `app.json` 中注册页面路径
3. 在 `cloudfunctions/` 下新建云函数（或直接复用现有 CRUD 模式）
4. 在云开发数据库中创建对应集合

## 技术栈

- 微信小程序原生框架（WXML + WXSS + JS）
- 微信云开发（云数据库 + 云函数）
- 无需后端服务器、无需域名备案
