# 产品需求文档：之欧智能语音工作台

## 1. 产品概述

之欧智能语音工作台是一款面向销售与效率场景的 AI 助手型工作台。通过「一句话」语音/文本输入触发 AI 自动分类、记录、提醒、报告全流程，集成行业情报、飞书妙记、项目跟进、客户项目跟踪等模块，实现销售全链路闭环管理。

目标用户为销售从业者、项目经理及需要高频记录与跟进的商务人群，核心价值在于降低信息录入成本，将碎片化的工作意图自动沉淀为结构化数据。

## 2. 核心功能

### 2.1 功能模块

#### A. 智能语音工作台（核心首页 `/voice-workbench`）
包含 6 个 Tab 标签页：
1. **语音录入**：语音或文字一句话触发 AI 分类 → 自动记录 → 自动设置提醒 → 自动生成报告
2. **日程日历**：日历视图 + 当日待办列表，右侧快捷入口
3. **备忘录**：随手记便签，可升级为日程，可关联到周月报
4. **工作记录**：按类型筛选（订单/拜访/报价/任务/电话/会议），卡片列表展示
5. **数据统计**：4 张核心数据卡片（订单数/客户拜访/报价次数/待办任务）+ 本周工作分布柱状图
6. **报告生成**：周报/出差报告一键生成，自动汇总本周所有工作记录

#### B. 行业情报 `/market-radar`
- **每日行业新闻**：按日期列表，新闻卡片包含标题、来源、摘要、关键词
- **招投标数据**：今日招标、今日中标两条流，金额、招标方、截止时间
- **关键词检索**：顶部搜索框，按关键词过滤新闻和招投标条目
- **日期切换**：默认今日，可切换最近 7 天 / 30 天

#### C. 飞书妙记 `/meeting-library`
- **4 类内容**：会议纪要 / 方法论 / 待办 / 感悟
- **组织维度**：按客户/组织分组列表（润和机械、中国航发、航天科工等）
- **时间维度**：按日期排序
- **待办一键加日程**：待办卡片提供"加入日程"按钮，自动写入日程
- **新建记录**：右下角浮动按钮快速创建

#### D. 项目跟进 `/project-tracker`
- **多客户 / 多销售项目组合视图**：网格化卡片展示
- **客户画像**：每个项目展示客户名称、行业、规模、关键联系人
- **阶段筛选**：销售阶段筛选器（线索/接洽/报价/成交/售后）+ 行业筛选
- **项目卡片**：显示项目名、阶段、金额、进度条、下一步动作

#### E. 客户项目跟踪 `/customer-tracker`
- **单项目深度视图**：进入后展示项目全貌
- **3 个 Tab**：
  1. **项目情况**：项目名称、金额、阶段、关键节点时间线
  2. **生产进度**：生产任务列表 + 进度条
  3. **客户画像**：客户基本信息、联系人、过往合作记录

## 3. 核心流程

### 3.1 一句话工作流
用户输入一句话 → AI 自动分类 → 自动记录 → 自动设置提醒 → 自动生成报告

### 3.2 备忘录闭环流
随手记便签 → 一键升级为日程 → 完成后标记闭环 → 数据自动汇入周报/月报

### 3.3 飞书妙记待办流转
会议中产生待办 → 标记"加入日程" → 自动同步到日程日历 → 执行完成后回写

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖棕色系
  - 深咖啡 `#6B4A30`
  - 咖啡 `#8B5E3C`
  - 焦糖 `#C9956B`
  - 浅摩卡 `#D4A574`
- **辅助色**：米白 `#FDF8F3`、浅灰 `#F5F5F5`、深灰 `#4A3320`、强调红 `#E15D5D`、成功绿 `#34C759`、信息蓝 `#3B82F6`
- **按钮风格**：大圆角胶囊/圆角矩形，主按钮使用渐变棕色，悬浮按钮使用深棕色圆形
- **字体**：中文 Noto Serif SC（标题）+ Noto Sans SC（正文），西文 Georgia
- **布局风格**：左侧固定侧边导航 + 右侧主内容区
- **图标风格**：线性描边图标结合少量面性填充

### 4.2 各页面设计概述

| 页面 | 关键元素 |
|------|----------|
| 工作台首页 | 顶部状态栏、流程说明、6 个 Tab、日历视图/记录卡片/数据卡片/报告生成按钮 |
| 行业情报 | 顶部搜索 + 日期选择、新闻列表、招投标分栏 |
| 飞书妙记 | 4 类切换 Tab、客户分组列表、待办快捷加日程 |
| 项目跟进 | 阶段筛选器、项目网格卡片 |
| 客户项目跟踪 | 3 个 Tab 深度视图、时间线、生产进度条、客户信息卡 |

### 4.3 交互动效
- 页面加载：侧边栏与主内容区采用错开淡入动画
- Tab 切换：内容区有轻微滑动过渡
- 卡片 hover：上浮并增强阴影
- 悬浮按钮 hover：放大并出现脉冲光环

## 5. 响应式设计
- 桌面端优先：侧边栏固定宽度 240px
- 平板端：侧边栏可折叠
- 移动端：侧边栏隐藏为抽屉菜单
